# CRIME CITY 3D v3 · 멀티플레이

플레이: https://dohyuni4321.github.io/wnstj-city/ · 이전 버전: https://dohyuni4321.github.io/wnstj-city/old/

## v3 새 기능
- U: 상점 — 미니건 · 레일건 · 멀티 로켓런처, 무적/스피드/슈퍼점프 포션(30초), 수류탄·TNT·탄약·수리·수배 지우기
- 특수 무기: 0 키 또는 마우스 휠로 선택 (한 번 사면 계속 보유)
- 길 차량·행인 동기화 (방장 기준), 친구가 탄 헬기·탱크·차는 진짜 그 차량이 같이 움직임
- 헬기·버스 4인, 일반 차 2인 탑승 / 같은 차량 탄 사람 이름표는 숨기고 밖에서는 위로 쌓아서 표시
- 마우스 모드: 지도·상점·채팅 닫으면 자동 복귀, 풀리면 클릭 한 번으로 복귀
- 총알이 마우스 포인터(마우스 모드는 화면 중앙 조준점) 쪽으로 발사
- 계엄령 사진 제거


## v2 새 기능
- 차량 2인 탑승: 친구 차 옆에서 E → 동승, 다시 E → 하차
- P: 마우스 모드(포인터 락) — 마우스로 시점/조준, 클릭 사격, A/D 옆걸음
- M: 큰 지도 — 친구 클릭하면 텔레포트
- Tab(꾹): 플레이어 목록 (이름·색깔·돈·수배·상태)
- 계엄령 선포 / 체포 알림이 모두에게 타이틀로 표시
- 경찰이 모두에게 보이고 다른 사람이 소환한 경찰도 죽일 수 있음
- 새 털기: 카지노(4) · 보석상(8) · ATM(30)
- 핫바: 총 6종 + 라이터 + 수류탄
- 추가 인터랙션: H 경적, B 손인사, V 근처 친구에게 송금, Y 슬롯머신

# CRIME CITY 3D · 멀티플레이

친구가 만든 CRIME CITY 3D 원본에 Supabase Realtime 멀티플레이를 붙인 버전.

**플레이:** https://dohyuni4321.github.io/wnstj-city/

## 멀티 방법
1. 접속하면 바로 싱글플레이로 시작되고, 왼쪽 아래에 **내 방 코드**가 표시됨
2. 친구가 자기 화면의 "친구 방 코드"에 그 코드를 입력하고 **참가**
3. 같은 도시에서 서로의 캐릭터·차량·총알·폭발이 보이고 채팅 가능 (인원 제한 없음)
4. "내 방으로 돌아가기"로 언제든 다시 내 방(싱글)으로

## 조작 추가/변경
- Space: 점프 (차량에서는 기존대로 핸드브레이크/사격)
- 좌클릭 또는 X: 도보 사격
- Enter: 채팅
- 모바일: JUMP 버튼

## 협동 요소
- 은행/가게 강탈 성공 시 근처(600 이내) 팀원에게 30% 팀 보너스
- 돈은 브라우저에 자동 저장

## 구조
- `index.html` — 게임 (원본 + 멀티 레이어), GitHub Pages로 배포
- `original-crime-city-3d.html` — 수정 전 원본
- 실시간 통신: Supabase Realtime (Broadcast + Presence), 별도 서버 불필요
- `server/` — 이전에 만든 Render WebSocket 서버 (현재 게임에서는 사용하지 않음)
